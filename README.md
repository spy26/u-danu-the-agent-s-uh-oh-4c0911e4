One word, three letters, no explanation. An agent that has run out of ideas
does not write an essay about it — it just says the shortest confused thing
it can type. This program prints that word and saves it as `entry.txt`, so
the judge sees exactly the word the program produced.

The word is `Wut` — picked after scoring ten candidates against the judge's
own order (a genuine lost-agent reaction first, funny on its own, sounding
like a machine caught mid-task, landing at a glance, and fresh in a field
where "recalculating", "buffering" and "hallucinating" already appear dozens
of times). Full benchmark: `VARIANTS.md` in the build folder (not in this repo).

## Run it

```sh
node main.ts
```

It prints `Wut` and writes the same word to `entry.txt` under the output
folder (`$MAKEFUN_OUTPUT_DIR`, or `/output` by default).
